## ผังการเชื่อมหน้า

```
index.html (หน้าแรก)
   └─ เมนู "ฟิล์มของเรา" / การ์ดแบรนด์ 4 ช่อง — เรียงจากแพงไปถูก (2026-07-30)
        ├─ products/brand-regionfilm.html  → โชว์สเปก Regionfilm ในหน้าเดียว (ไม่มีหน้ารุ่นย่อย)
        ├─ products/brand-ultraguard.html  → model-ultraguard-* (Nanoceramic, Super Clear)
        ├─ products/brand-3m.html          → model-3m-* (Ceramate, Ceramic Ultra Clear)
        └─ products/brand-finnix.html      → model-finnix-* (UV Guard, Ceramic, Extra Clear, Titanium, Crystalize)
```

ลำดับนี้ใช้เหมือนกันทั้ง **เมนูดรอปดาวน์ · แถวโลโก้แบรนด์หน้าแรก · คอลัมน์ "ฟิล์มของเรา" ใน footer · การ์ดเลือกรุ่นในหน้าแบรนด์**
ถ้าจะเปลี่ยนลำดับใหม่ ต้องแก้ให้ตรงกันทั้ง 4 จุด

ทุกหน้าใช้ **โค้ด header/footer ชุดเดียวกัน** — แถบเมนูเป็น **แคปซูลลอยสีกรมท่า**
(โลโก้ขาว = ปุ่มกลับหน้าแรก + เมนู dropdown + ปุ่มทองโทร/คัดลอกเบอร์)
**ปุ่มลอย LINE/โทร มุมขวาล่างถูกถอดออกทั้งเว็บแล้ว (2026-07-30)** ตามที่เจ้าของร้านสั่ง
